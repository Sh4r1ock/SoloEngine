# SoloEngine 前端设计系统

## 1. 设计概述

### 1.1 设计理念
SoloEngine 基于 **现代简约风格** 和 **用户为中心** 的设计原则，创建直观、一致、可访问的用户界面。设计系统强调 **功能层级清晰**、**交互反馈明确** 和 **视觉平衡和谐**。

### 1.2 设计目标
- **专业性**：体现Agent编排工具的技术专业性
- **易用性**：降低用户学习成本，直观的操作流程
- **扩展性**：设计系统可随产品功能扩展而演进
- **一致性**：保持跨组件、跨页面的视觉和交互一致性

### 1.3 目标用户
- **技术开发者**：熟悉Agent概念，需要高效编排工具
- **产品经理**：需要可视化配置AI工作流
- **研究人员**：实验不同Agent组合和提示词策略

## 2. 设计原则

### 2.1 核心原则
1. **一致性**：组件、交互和视觉效果在整个应用中保持一致
2. **层次性**：通过尺寸、颜色和间距建立明确的信息层级
3. **可用性**：界面直观易用，减少用户学习成本
4. **响应性**：适应不同设备和屏幕尺寸
5. **无障碍性**：确保所有用户都能访问和使用

### 2.2 交互原则
- **即时反馈**：用户操作后立即提供视觉或状态反馈
- **渐进式揭示**：复杂功能逐步展示，避免界面过载
- **容错设计**：提供撤销、重做和错误恢复机制

## 3. 色彩系统

### 3.1 色彩架构
基于 Material Design 色彩理论，建立三层色彩架构：

#### 主色系统 - 用于品牌和主要操作
```css
--primary-100: #3F51B5;  /* 主要按钮、重要标签、激活状态 */
--primary-200: #757de8;  /* 悬停状态、次要强调 */
--primary-300: #dedeff;  /* 背景高亮、轻度强调 */
```

#### 强调色系统 - 用于状态和提醒
```css
--accent-100: #2196F3;   /* 成功状态、链接、积极指标 */
--accent-200: #003f8f;   /* 深度状态、重要提醒 */
```

#### 中性色系统 - 用于文本和背景
```css
--text-100: #333333;     /* 主要文字、标题 */
--text-200: #5c5c5c;     /* 次要文字、描述 */
--bg-100: #FFFFFF;       /* 卡片、面板背景 */
--bg-200: #f5f5f5;       /* 页面背景、分隔区域 */
--bg-300: #cccccc;       /* 边框、分隔线 */
```

#### 状态色（扩展）
```css
--success: #4CAF50;      /* 成功操作、正向数据 */
--warning: #FF9800;      /* 警告提醒 */
--error: #F44336;        /* 错误状态、负向数据 */
```

### 3.2 色彩应用规范

#### 品牌标识
- **主品牌色**：`#3F51B5` (--primary-100)
- **辅助品牌色**：`#2196F3` (--accent-100)
- **品牌标识**：使用渐变背景 `linear-gradient(135deg, #3F51B5, #2196F3)`

#### 文本颜色规范
- **一级文本**：`#333333` (--text-100) - 标题、主要内容
- **二级文本**：`#5c5c5c` (--text-200) - 描述、辅助信息
- **三级文本**：`#9ca3af` (--text-tertiary) - 占位符、禁用状态
- **链接文本**：`#2196F3` (--accent-100) - 可点击链接

#### 背景颜色规范
- **页面背景**：`#f5f5f5` (--bg-200)
- **卡片背景**：`#FFFFFF` (--bg-100)
- **悬浮背景**：`#f8f9fa` (--bg-tertiary)
- **高亮背景**：`#dedeff` (--primary-300)

## 5. 布局与间距

### 5.1 布局系统
#### 页面结构
```
┌─────────────────────────────────────┐
│          应用栏/导航栏 (64px)        │
├─────────────────────────────────────┤
│                                     │
│           主要内容区域               │
│                                     │
└─────────────────────────────────────┘
```

#### 网格系统
- **基础间距单位**：8px
- **内容区域最大宽度**：1200px（桌面端）
- **列布局**：使用Flexbox/Grid实现响应式
- **断点设置**：
  - 移动端：< 768px
  - 平板端：768px - 1024px
  - 桌面端：> 1024px

### 5.2 间距系统
基于8px的倍数构建间距系统：
```css

--spacing-xl: 32px;   /* 页面区块间距 */

```

### 5.3 圆角系统

## 7. 交互与动效

### 7.1 过渡效果
```css
--duration-instant: 0.1s;  /* 即时反馈 */
--duration-fast: 0.2s;     /* 按钮悬停 */
--duration-base: 0.3s;     /* 卡片悬停、页面切换 */
--duration-slow: 0.5s;     /* 复杂动画 */

--ease-in-out: cubic-bezier(0.645, 0.045, 0.355, 1);
--ease-out: cubic-bezier(0.215, 0.61, 0.355, 1);
--ease-in: cubic-bezier(0.55, 0.055, 0.675, 0.19);
```

### 7.2 微交互
1. **点击反馈**：轻微的缩放（scale: 0.98）或颜色变化
2. **加载状态**：旋转指示器、进度条或骨架屏
3. **成功/错误反馈**：轻量级通知，自动消失
4. **拖拽反馈**：半透明预览、目标区域高亮

### 7.3 动效规范
- **页面切换**：淡入淡出，duration-base
- **模态框弹出**：从中心缩放，duration-base
- **下拉菜单**：从上向下展开，duration-fast
- **工具提示**：淡入 + 轻微上移，duration-fast

## 8. 响应式设计

### 8.1 断点定义
```css
/* 移动端优先 */
@media (min-width: 768px) { /* 平板 */ }
@media (min-width: 1024px) { /* 桌面 */ }
@media (min-width: 1280px) { /* 大桌面 */ }
```

### 8.2 适配策略
1. **内容优先**：确保核心内容在不同尺寸下都可用
2. **渐进增强**：大屏幕上提供更丰富的功能和信息
3. **触摸友好**：移动端交互元素最小44×44px
4. **字体适配**：相对单位（rem）配合媒体查询

### 8.3 布局变体
#### 桌面端 (≥1024px)
- 固定侧边栏 + 灵活内容区
- 多列布局，充分利用水平空间
- 悬停交互效果

#### 平板端 (768px-1024px)
- 单列布局，垂直滚动
- 适度简化界面元素
- 触摸优化的交互尺寸

#### 移动端 (<768px)
- 全屏单列布局
- 汉堡菜单导航
- 大点击区域，简化操作流程

```css

  background-color: var(--primary-100);
```
