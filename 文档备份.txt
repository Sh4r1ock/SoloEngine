## 二、核心模块实现

### 2.1 后端核心代码

#### 2.1.1 节点基类（models/node.py）

```python
from abc import ABC, abstractmethod
from typing import Literal, Dict, Any

class AgentNode(ABC):
    id: str
    name: str
    node_type: Literal["orchestrator", "planner", "executor"]
    config: Dict[str, Any]
    
    @abstractmethod
    async def run(self, global_context: Dict[str, Any]) -> Dict[str, Any]:
        pass

class OrchestratorNode(AgentNode):
    async def run(self, global_context: Dict[str, Any]) -> Dict[str, Any]:
        pass

class PlannerNode(AgentNode):
    async def run(self, global_context: Dict[str, Any]) -> Dict[str, Any]:
        pass

class ExecutorNode(AgentNode):
    async def run(self, global_context: Dict[str, Any]) -> Dict[str, Any]:
        pass
```

#### 2.1.3 上下文管理器（core/context\_manager.py）

```python
class ContextManager:
    def __init__(self):
        self.global_context = {
            "user_input": "",
            "current_plan": None,
            "execution_history": []
        }
    
    def update(self, key: str, value: Any):
        self.global_context[key] = value
    
    def get(self, key: str) -> Any:
        return self.global_context.get(key)
```

### 2.2 前端核心组件

#### 2.2.1 画布组件（components/Canvas/）

* 使用React Flow实现节点拖拽、连线、删除

* 支持三种节点类型渲染（只设定一种类型的节点。通过下拉栏，进行选择，选择不同的节点类型。他们除了采用不同的提示词模板外，完全相同）

* 实时保存画布状态到后端

#### 2.2.2 节点属性编辑器（components/PropertyEditor/）

* 节点简介

* 系统提示词编辑框（支持变量插值，如{available}）

* 用户提示词编辑框（支持变量插值，如{available}）

* 助手提示词编辑框（支持变量插值，如{available}，该框可隐藏）

* 管理框，如果节点A-连线>节点B,就可以在节点A的管理框中 选择节点B，模仿的是公司上下级关系。此时，选择B后，用户无需手动配置。通过预设的提示词模板，调用节点B的简介（说明什么时候调用节点B、节点B的作用是什么），这个提示词模板是固定的，设置后像引用变量一样自动配置。但用户可以自行修改。

* 技能绑定区（多选或标签形式，支持MCP和Function Calling）

* skills区（可以选定不同的skill区（这是后端下一步设计，可以创建不同的skills区，每个区可以放置不同的skill。在工作流外管理））

* 模型配置（选择LLM及参数）

#### 2.2.3 连线智能配置（utils/promptGenerator.ts）

```typescript
export const generateOrchestratorPrompt = (orchestratorNode: Node, plannerNodes: Node[]): string => {
  const plannerInfo = plannerNodes.map(node => 
    `规划师${node.data.name}（简介：${node.data.desc || '无'}）可用于拆解复杂目标。`
  ).join('\n');
  return `你是总指挥...可用助手：\n${plannerInfo}`;
};

export const generatePlannerPrompt = (plannerNode: Node, executorNodes: Node[]): string => {
  const executorList = executorNodes.map(node => ({
    id: node.id,
    name: node.data.name,
    desc: node.data.desc || '无'
  }));
  return `你是规划师...可用执行者：${JSON.stringify(executorList)}`;
};
```

## 三、API接口定义

### 3.1 RESTful API

| 接口功能 | 方法   | 路径                                    | 请求体                                             | 响应体                                        |
| ---- | ---- | ------------------------------------- | ----------------------------------------------- | ------------------------------------------ |
| 获取画布 | GET  | /api/v1/projects/{project\_id}/canvas | N/A                                             | {"code": 200, "data": {...}}               |
| 更新画布 | PUT  | /api/v1/projects/{project\_id}/canvas | {"nodes": \[...], "edges": \[...]}              | {"code": 200, "data": {...}}               |
| 启动执行 | POST | /api/v1/projects/{project\_id}/run    | {"input": "..."}                                | {"code": 200, "data": {"task\_id": "..."}} |
| 获取工具 | GET  | /api/v1/tools                         | N/A                                             | {"code": 200, "data": \[...]}              |
| 注册工具 | POST | /api/v1/tools                         | {"name": "...", "type": "...", "config": {...}} | {"code": 201, "data": {...}}               |

### 3.2 WebSocket事件（AG-UI协议适配）

| 事件类型               | 方向      | 数据结构                                                   |
| ------------------ | ------- | ------------------------------------------------------ |
| agent-update       | 服务器→客户端 | {"node\_id": "...", "status": "...", "message": "..."} |
| tool-call          | 服务器→客户端 | {"tool\_id": "...", "args": {...}, "result": "..."}    |
| response-streaming | 服务器→客户端 | {"text": "...", "done": false}                         |
| execution-complete | 服务器→客户端 | {"task\_id": "...", "result": "..."}                   |
| execution-start    | 客户端→服务器 | {"project\_id": "...", "input": "..."}                 |
