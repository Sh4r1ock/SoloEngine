## 三、设计理念

### 3.1 Trae对话栏设计参考

基于Trae IDE的Chat模式设计理念，本重构遵循以下原则：

```
核心设计原则：
- 充分利用空间：消息占满容器宽度，不居中限制
- 角色区分：用户消息右对齐，助手消息左对齐
- 简洁清晰：减少视觉噪音，突出内容本身
- 响应式设计：适应对话栏宽度变化（可拖拽调整）
- 流式输出友好：支持实时流式内容的优雅展示
- 亮色主题优化：针对亮色主题进行样式优化
```

### 3.2 对话栏宽度可变性说明

**重要约束**：对话栏宽度是可变的！

```typescript
// RunPanel.tsx 第175行
const [panelRatios, setPanelRatios] = useState([1, 4, 4, 1]);
// panelRatios[1] = 4 表示对话栏占 4/10
// 用户可以通过拖拽分隔线调整宽度
```

**设计规则**：
| 内容类型 | 设计方式 | 原因 |
|----------|----------|------|
| 消息宽度 | **不能写死**，占满容器或使用较大百分比 | 窄面板需充分利用空间 |
| 输入框宽度 | **不能写死**，使用100% | 对话栏宽度可变 |
| 头像尺寸 | **必须写死**，固定28px | 固定元素，不随容器变化 |
| 圆角大小 | **必须写死**，固定值 | 固定样式 |
| 间距/内边距 | **必须写死**，固定值 | 固定样式 |
| 字体大小 | **必须写死**，固定值 | 固定样式 |

```tsx
const toggleReasoningCollapse = (msgId: string) => {
  setCollapsedReasoning(prev => {
    const newSet = new Set(prev);
    if (newSet.has(msgId)) {
      newSet.delete(msgId);
    } else {
      newSet.add(msgId);
    }
    return newSet;
  });
};

const toggleToolCallsCollapse = (msgId: string, blockIdx: number, tcIdx: number) => {
  const key = `${msgId}-${blockIdx}-${tcIdx}`;
  setCollapsedToolCalls(prev => {
    const newSet = new Set(prev);
    if (newSet.has(key)) {
      newSet.delete(key);
    } else {
      newSet.add(key);
    }
    return newSet;
  });
};
```
