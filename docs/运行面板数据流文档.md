**沙箱安全机制:**
```python
class SandboxedFileSystem:
    def _resolve_path(self, relative_path: str) -> str:
        """解析相对路径并验证是否在沙箱内"""
        absolute_path = os.path.abspath(os.path.join(self.base_path, relative_path))
        
        # 关键安全检查：确保路径在沙箱内
        if not absolute_path.startswith(self.base_path):
            raise PermissionError(f"Access denied: path outside sandbox")
        
        return absolute_path
```

```
AgenticFlowCompiler._compile_node()
       │
       ├──► 获取节点配置
       │    node_data.get("llm_config_id")
       │
       ├──► 如果有 llm_config_id:
       │    ├── 从 llm_configs 字典获取配置
       │    ├── 解密 API Key
       │    │    encryption_service.decrypt(config.api_key)
       │    └── 使用配置的 provider, model, base_url
       │
       ├──► 否则使用默认配置:
       │    ├── 查找 is_default = True 的配置
       │    └── 使用默认配置
       │
       └──► 创建 SoloAgentConfig
```

### 6. WebSocket实时通信数据流

#### 6.1 连接建立

```
前端                              WebSocket                         后端
───────────────────────────────────────────────────────────────────────
useRunWebSocket({ sessionId })
       │
       ├──► 构建 WebSocket URL
       │    ws://host/api/v1/run/ws/{sessionId}?token={token}
       │
       ├──► 创建 WebSocket 连接
       │    new WebSocket(wsUrl)
       │                                    │
       │                                    ▼
       │                          run.py → run_websocket()
       │                                    │
       │                                    ├── 验证 Token
       │                                    ├── 验证用户
       │                                    ├── 接受连接
       │                                    └── 注册到 _active_websockets
       │
       ├──► onopen
       │    setIsConnected(true)
       │    发送 ping
       │
       └──► 心跳保活
            定期发送 ping
            接收 pong
```

#### 6.2 事件类型

| 事件类型 | 方向 | 描述 |
|----------|------|------|
| `ping` | 前端→后端 | 心跳检测 |
| `pong` | 后端→前端 | 心跳响应 |
| `execute` | 前端→后端 | 执行工作流请求 |
| `execution_start` | 后端→前端 | 执行开始 |
| `agent_start` | 后端→前端 | Agent开始执行 |
| `stream` | 后端→前端 | 流式输出内容 |
| `tool_call` | 后端→前端 | 工具调用事件 |
| `tool_result` | 后端→前端 | 工具调用结果 |
| `skill_call` | 后端→前端 | Skill调用事件 |
| `mcp_call` | 后端→前端 | MCP调用事件 |
| `child_agent_start` | 后端→前端 | 子Agent开始 |
| `child_agent_complete` | 后端→前端 | 子Agent完成 |
| `agent_complete` | 后端→前端 | Agent执行完成 |
| `execution_complete` | 后端→前端 | 执行完成 |
| `execution_error` | 后端→前端 | 执行错误 |

**位置:** `data/database/soloengine.db`

**表结构:**

```sql
-- 用户表
CREATE TABLE users (
    id VARCHAR(36) PRIMARY KEY,
    username VARCHAR(255) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE,
    hashed_password VARCHAR(255) NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    is_superuser BOOLEAN DEFAULT FALSE,
    created_at DATETIME,
    updated_at DATETIME,
    last_login DATETIME,
    version INTEGER DEFAULT 1
);

-- 运行项目表
CREATE TABLE run_projects (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id),
    name VARCHAR(255) NOT NULL,
    folder_path VARCHAR(1000) NOT NULL,
    description TEXT,
    is_active BOOLEAN DEFAULT TRUE,
    last_accessed_at DATETIME,
    created_at DATETIME,
    updated_at DATETIME,
    version INTEGER DEFAULT 1
);

-- 最近项目表
CREATE TABLE recent_projects (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id),
    project_id VARCHAR(36) REFERENCES run_projects(id),
    folder_path VARCHAR(1000) NOT NULL,
    project_name VARCHAR(255) NOT NULL,
    accessed_at DATETIME,
    version INTEGER DEFAULT 1
);

-- 会话表
CREATE TABLE agentic_flow_sessions (
    id VARCHAR(36) PRIMARY KEY,
    agentic_flow_id VARCHAR(36),
    user_id VARCHAR(36) REFERENCES users(id),
    run_project_id VARCHAR(36) REFERENCES run_projects(id),
    status VARCHAR(50) DEFAULT 'pending',
    error TEXT,
    token_usage JSON,
    duration_ms INTEGER,
    started_at DATETIME,
    completed_at DATETIME,
    created_at DATETIME,
    updated_at DATETIME,
    version INTEGER DEFAULT 1
);

-- 会话消息表
CREATE TABLE session_messages (
    session_id VARCHAR(36) REFERENCES agentic_flow_sessions(id),
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id),
    role VARCHAR(20) NOT NULL,
    data JSON NOT NULL,
    message_index INTEGER NOT NULL,
    prompt_tokens INTEGER,
    completion_tokens INTEGER,
    total_tokens INTEGER,
    created_at DATETIME,
    PRIMARY KEY (session_id, id)
);

-- 执行步骤表
CREATE TABLE execution_steps (
    id VARCHAR(36) PRIMARY KEY,
    session_id VARCHAR(36) REFERENCES agentic_flow_sessions(id),
    step_type VARCHAR(50) NOT NULL,
    node_id VARCHAR(36),
    node_name VARCHAR(255),
    thought TEXT,
    action VARCHAR(255),
    action_input JSON,
    observation TEXT,
    error TEXT,
    duration_ms INTEGER,
    created_at DATETIME,
    version INTEGER DEFAULT 1
);

-- 工具调用记录表
CREATE TABLE tool_call_records (
    id VARCHAR(36) PRIMARY KEY,
    session_id VARCHAR(36) REFERENCES agentic_flow_sessions(id),
    tool_name VARCHAR(255) NOT NULL,
    arguments JSON,
    result TEXT,
    error TEXT,
    duration_ms INTEGER,
    created_at DATETIME,
    version INTEGER DEFAULT 1
);

-- LLM配置表
CREATE TABLE llm_configs (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id),
    name VARCHAR(255) NOT NULL,
    provider VARCHAR(50) NOT NULL,
    model_name VARCHAR(255) NOT NULL,
    api_key TEXT,              -- 加密存储
    base_url VARCHAR(500),
    temperature FLOAT DEFAULT 0.7,
    max_tokens INTEGER DEFAULT 2048,
    top_p FLOAT DEFAULT 1.0,
    frequency_penalty FLOAT DEFAULT 0.0,
    presence_penalty FLOAT DEFAULT 0.0,
    timeout INTEGER DEFAULT 60,
    extra_params JSON,
    is_default BOOLEAN DEFAULT FALSE,
    is_active BOOLEAN DEFAULT TRUE,
    created_at DATETIME,
    updated_at DATETIME,
    version INTEGER DEFAULT 1
);
```
