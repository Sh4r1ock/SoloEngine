## 组件概述

### RunPanel 组件定位

运行面板是 SoloEngine 的核心功能组件，提供以下能力：

| 功能模块 | 描述 |
|---------|------|
| **项目管理** | 选择项目文件夹、切换项目、最近项目记录 |
| **会话管理** | 创建会话、切换会话、删除会话、加载历史会话 |
| **工作流执行** | 通过 WebSocket/SSE 执行 AI Agent 工作流 |
| **文件系统** | 浏览项目文件、编辑文件、自动保存 |
| **实时通信** | 接收流式输出、工具调用事件、子Agent事件 |

## 数据库表结构

### 运行面板直接使用的数据库表

#### 1. run_projects - 运行项目表

```sql
CREATE TABLE run_projects (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id),
    name VARCHAR(255) NOT NULL,
    folder_path VARCHAR(1000) NOT NULL,
    description TEXT,
    is_active BOOLEAN DEFAULT TRUE,
    last_accessed_at DATETIME,
    created_at DATETIME,
    updated_at DATETIME,
    version INTEGER DEFAULT 1
);

-- 索引
CREATE INDEX ix_run_projects_user_active ON run_projects(user_id, is_active);
```

**用途**: 存储用户选择的项目文件夹信息

#### 2. recent_projects - 最近项目表

```sql
CREATE TABLE recent_projects (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id),
    project_id VARCHAR(36) REFERENCES run_projects(id),
    folder_path VARCHAR(1000) NOT NULL,
    project_name VARCHAR(255) NOT NULL,
    accessed_at DATETIME,
    version INTEGER DEFAULT 1
);

-- 索引
CREATE INDEX ix_recent_projects_user_accessed ON recent_projects(user_id, accessed_at);
```

**用途**: 记录用户最近访问的项目，用于快速切换

#### 3. agentic_flow_sessions - 会话表

```sql
CREATE TABLE agentic_flow_sessions (
    id VARCHAR(36) PRIMARY KEY,
    agentic_flow_id VARCHAR(36) REFERENCES agentic_flows(id),
    user_id VARCHAR(36) REFERENCES users(id),
    run_project_id VARCHAR(36) REFERENCES run_projects(id),
    status VARCHAR(50) DEFAULT 'pending',
    error TEXT,
    token_usage JSON,
    duration_ms INTEGER,
    started_at DATETIME,
    completed_at DATETIME,
    created_at DATETIME,
    updated_at DATETIME,
    version INTEGER DEFAULT 1
);

-- 索引
CREATE INDEX ix_sessions_user_id ON agentic_flow_sessions(user_id);
CREATE INDEX ix_sessions_agentic_flow_id ON agentic_flow_sessions(agentic_flow_id);
CREATE INDEX ix_sessions_status ON agentic_flow_sessions(status);
CREATE INDEX ix_sessions_created_at ON agentic_flow_sessions(created_at);
CREATE INDEX ix_sessions_user_status ON agentic_flow_sessions(user_id, status);
```

**用途**: 存储会话元数据（状态、时间、token统计）

#### 4. session_messages - 会话消息表

```sql
CREATE TABLE session_messages (
    session_id VARCHAR(36) REFERENCES agentic_flow_sessions(id),
    id VARCHAR(36),
    user_id VARCHAR(36) REFERENCES users(id),
    role VARCHAR(20) NOT NULL,
    data JSON NOT NULL,
    message_index INTEGER NOT NULL,
    prompt_tokens INTEGER,
    completion_tokens INTEGER,
    total_tokens INTEGER,
    created_at DATETIME,
    PRIMARY KEY (session_id, id)
);

-- 索引
CREATE INDEX ix_session_messages_session_id ON session_messages(session_id);
CREATE INDEX ix_session_messages_user_id ON session_messages(user_id);
CREATE INDEX ix_session_messages_role ON session_messages(role);
CREATE INDEX ix_session_messages_session_index ON session_messages(session_id, message_index);
CREATE INDEX ix_session_messages_created_at ON session_messages(created_at);
```

**用途**: 存储会话中的对话消息，data字段存储消息内容数组

#### 5. llm_configs - LLM配置表

```sql
CREATE TABLE llm_configs (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id),
    name VARCHAR(255) NOT NULL,
    provider VARCHAR(50) NOT NULL,
    model_name VARCHAR(255) NOT NULL,
    api_key TEXT,              -- 加密存储
    base_url VARCHAR(500),
    temperature FLOAT DEFAULT 0.7,
    max_tokens INTEGER DEFAULT 2048,
    top_p FLOAT DEFAULT 1.0,
    frequency_penalty FLOAT DEFAULT 0.0,
    presence_penalty FLOAT DEFAULT 0.0,
    timeout INTEGER DEFAULT 60,
    extra_params JSON,
    is_default BOOLEAN DEFAULT FALSE,
    is_active BOOLEAN DEFAULT TRUE,
    created_at DATETIME,
    updated_at DATETIME,
    version INTEGER DEFAULT 1
);
```

**用途**: 存储LLM配置，RunPanel加载默认配置用于创建默认Agent
